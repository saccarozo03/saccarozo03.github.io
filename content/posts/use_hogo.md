## Mục tiêu bài này
- Biết cấu trúc 1 bài viết “đẹp” trong Hugo + PaperMod
- Nắm các “lệnh” Markdown quan trọng (heading, list, link, ảnh, quote, table…)
- Biết cách chèn code (C, bash, json…) và tránh lỗi hay gặp

---

## 1) Bố cục bài viết chuẩn (khuyến nghị)
Mình dùng 1 format cố định để viết learning log, dễ đọc và nhất quán:

1. **Mục tiêu**
2. **TL;DR**
3. **Nội dung chính** (chia theo mục)
4. **Ví dụ code + cách chạy**
5. **Lỗi thường gặp**
6. **Checklist / Next steps**
7. **Tài liệu tham khảo**

Bạn có thể copy “template nhanh” cho các bài sau:

```md
## Mục tiêu hôm nay
- [ ] ...
- [ ] ...

## TL;DR
- ...
- ...

---

## Nội dung chính
### 1. ...
### 2. ...

---
